One place for every sourced price on the site

Each live tool starts with the original AgriLife spreadsheet's own default numbers, updated where a current market price was available — never guessed or invented. This page lists every one of those updates in one place: what it's for, the current value, where it came from, and how current it is — so it's easy to see at a glance what's fresh, what's still an open gap, and where to look when it's time to refresh everything at once.

One shared "Market prices & factors" store

Starting 2026-09-21, every price and bull-economics figure on this page is entered once, in the "Market prices & factors" calculator on the home page, and persisted in this browser under the tamuDecisionAidsMarketPrices key. Every tool below (A1/A2, D1/Stockers, B1a, and the home page's own "Cow operating cost (BCU)" calculator) reads that same value instead of keeping its own separate copy — each field stays freely editable per-page as a local override, but the default everywhere now comes from one place. This replaces the old pattern of pasting the same number into every tool by hand, and closes the drift it caused: building this store surfaced a herd-bull cost that had silently diverged into three different numbers across the site ($4,500/hd on the home page's BCU calculator, $4,000/hd on B1a, $4,000/hd on A2) — all now unified at $4,500/hd, 4-yr life, 2% death loss, 1,650.7 lb salvage weight (see "Herd bull economics" in the table below). Weight-based prices (steer, heifer, cull cow) still interpolate off their own weight/price curves — see the curves card below — but those curves are now rescaled live to whatever flat price is entered in the shared store, not fixed at build time.

Refreshing all of this later

When it's time to update prices again: re-pull the three USDA AMS reports above for a current week, re-screenshot or re-pull a current "Local Texas Auction Data" report for the weight-class curves, then enter the new flat numbers once in the home page's "Market prices & factors" calculator — every tool that reads the shared store picks the change up automatically (live in every open tab, and on next load elsewhere), with each weight-class curve rescaling itself the same rescale-to-anchor way rather than being replaced outright, so weight sliders keep behaving sensibly across their whole range, not just at the default point. The few fields that don't yet read from the shared store (see "Not yet sourced" above) still need a manual edit on their own page. Every place a number changes, it should get the same treatment as everything on this page: cited here, dated, and flagged on its own tool page.

This page is a reference index, not a calculator — it doesn't recompute anything itself. See each tool's own page for the live inputs and results. Report IDs (e.g. ams_1953.pdf) refer to USDA AMS's Market News reports at ams.usda.gov/mnreports.
